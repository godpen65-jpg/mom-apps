# 3D 뮤지엄 그리스 로마 신화 QR 모음 (greek-myth)

교원 빨간펜 「3D 뮤지엄 그리스 로마 신화」 전 30권. 책마다 앞장에 QR이 2개 있다.

- 🎬 **북쇼츠 영상 보기** → 주소가 `http://qr.kyowon.kr/1UnDeH…` 로 시작
- 🎧 **전체 이야기 듣기** → 주소가 `http://qr.kyowon.kr/1UnDd9…` 로 시작

`index.html` 한 장짜리. 링크 데이터는 맨 아래 `<script>`의 `WORLDS` 배열.
유료 책 내용이라 첫 화면(공개 목록)에는 안 넣고 **비밀 앱 모음**에만 넣었다. `noindex` 걸어둠.

## 만든 방법 (2026-10-20)

1. 엄마가 찍은 사진 29장 (권 목록 1장 + 권별 QR 28장)
2. 사진에서 QR 56개를 프로그램으로 읽음 (전부 읽힘)
3. 사진에 권 번호가 안 보여서 두 가지로 맞춤
   - QR 주소 뒷부분이 **권 순서대로 커지는 일련번호**라서, 정렬하면 순서가 나옴
   - 사진에 보이는 인물 이름으로 확인 (세멜레=2권, 메티스=3권, 에오스=12권, 멜라니온=15권, 레토=20권, 폴리데크테스=21권, 텔라몬=22권, 헤라=23권, 라티누스=30권 등)
   - 두 방법 결과가 전부 맞아떨어짐
4. 페이지 프레임 색으로 세계 구분: 청록=올림포스 월드(1~10), 분홍=다이내믹 랜드(11~20), 금색=히어로즈 로드(21~30)

## 빠졌던 권

- 처음 사진에 1권, 19권이 없었음 → 2026-10-21에 사진 받아서 채움. 이제 30권 전부 있음
- QR 일련번호로도 확인: 1권은 2권보다 앞, 19권은 18권과 20권 사이에 딱 맞음

## 확인 못 한 것

- `qr.kyowon.kr` 주소가 작업 환경(해외 서버)에서는 아예 안 열려서, 눌렀을 때 어떤 화면이 나오는지(교원 플레이어인지, 유튜브인지, 로그인이 필요한지) 확인 못 함.
- QR은 `www.kyowonedu.com/KEM/NewqrCodeView.jsp?idx=…`(빨간펜 QR 코드 영상) 페이지로 감. 로그인 없이 재생됨.
- **다운로드는 막혀 있음.** 개발자 도구를 열면 디버거가 멈추게 해 두었고 SecuKit NX(캡처 방지)도 붙어 있음. 교원이 일부러 막은 것이라 우회하지 않고 링크로 보기로 함.
- 19·20·30권 제목·에피소드는 권 목록 사진에서 빛 반사로 흐린 부분을 확대해서 읽음.

## 파트 버튼 (2026-10-21)

- 스크롤이 길어서 위에 **전체 / 올림포스 월드 / 다이내믹 랜드 / 히어로즈 로드** 버튼 4개를 둠. 누르면 그 파트 10권이 전부 보임
- 버튼 줄은 화면 위에 붙어 있어서 내려가도 계속 보임
- 처음 열면 올림포스 월드. 마지막에 누른 파트를 기억해서 다음에 그 파트로 열림 (localStorage `greek-myth-tab`)

## 권별 캐릭터 그림 (2026-10-21)

- 제목 오른쪽에 권마다 귀여운 치비 캐릭터 그림(58px). Higgsfield AI(`gpt_image_2_5`)로 30장, 장당 0.25크레딧 = 7.5크레딧
- 교원 표지를 베끼지 않고, 각 권 주인공을 새로 그림 (2권 번개 든 제우스, 23권 사자 망토 헤라클레스 등. `index.html`의 `PIC` 주석 참고)
- 작업 환경에서 Higgsfield 서버로 다운로드가 막혀서 **저장소에 파일을 안 넣고 Higgsfield 주소(`_min.webp` 작은 버전)를 바로 연결**함
- Higgsfield에서 그림을 지우면 안 보임. 안 열리면 그림 칸은 자동으로 사라짐(`onerror`)
