# 티니핑 도감 작업메모

## 홈 화면 앱 아이콘 (2026-10-13)

- 홈 화면 이름 **티니핑도감**, 아이콘은 목록 이모지 그대로, 배경색 `#ffe0ef`
- 넣은 파일: `manifest.json`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`
- `index.html` `<head>`의 `<!-- 홈 화면 앱 설치용 -->` 아래 4줄이 이 파일들을 연결함
- 크롬에서 열고 ⋮ → 홈 화면에 추가 하면 주소창 없이 앱처럼 열림
- 전체 정리: mom-apps 저장소의 `홈화면_앱아이콘_메모.md`
- 크롬 자동 설치 팝업은 막고, 오른쪽 아래에 앱 아이콘 + '홈 화면에 추가' 작은 버튼을 띄움 (`install.js`). 설치했거나 앱으로 열면 안 보임

## 쥬얼스타(시즌 7) 그림 추가 (2026-11-19)

- 팬 위키 `List of Teeniepings/Season 7` 기준. 위키 이름 수는 25명 그대로, 그림이 새로 올라온 16명을 넣음
  (팡팡핑 빠밤핑 앙앙핑 잉잉핑 코디핑 시고르핑 폴짝핑 냐냥핑 낭낭핑 아서핑 아리아핑 쏭쏭핑 디바핑 뮤즈핑 티키핑 타카핑)
- 그림은 위키 원본(png)을 긴 쪽 240px webp 로 줄여 `img/` 에 저장. DATA 의 `i` 는 위키 경로(예: `d/d3/Pop-popping_Render_2.png`)
- 특징으로 찾기용 머리색(hc)·몸 색(bc)·장식/옷(t)은 그림을 보고 채움. 앙앙핑·잉잉핑·빠밤핑은 공룡·상어 옷이라 몸 색 = 옷 색
- 영어 이름 바뀜: 앙앙핑 T-raping → Wahwahping, 잉잉핑 Pteraping → Whinyping
- 디바핑·뮤즈핑은 위키에서 '전설 스테이지 티니핑' → 무리를 `레전드`로, 로열 바로 뒤에 둠
- 아직 그림 없음: 까밍핑, 불꽃핑, 포포핑, 비타핑, 마린핑 → 위키에 올라오면 같은 방법으로 추가
- 맨 아래 숫자: '조회수 ○회' (방문 횟수). 처음 온 기기 수(teenieping-people)는 화면에 안 보이고 방문자 현황판에서만 봄
