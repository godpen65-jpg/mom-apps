# 일기 5문장으로 쓰기 — 앱 제작용 자료

초등 1학년이 네모 칸에 낱말(재료)만 골라 넣어 5문장 일기를 완성하는 앱.
모든 낱말 데이터는 함께 있는 `diary5_data.json`에 들어 있다. 이 문서는 그 데이터의 구조와 앱이 지켜야 할 규칙을 설명한다.

## 1. 5문장 틀 (v2.0 — 앱과 정리본 PDF가 같은 틀을 쓴다)

| 번호 | 단계 | 문장 틀 | 아이가 고를 것 / 재료 |
|---|---|---|---|
| 1 | 장면 | 오늘 나는 [누구]와(과) [어디]에서 [무엇]을(를) [어떻게] [행동]. | 장소 → 무엇 → 누구 (`places`, `fillers`) · 어떻게는 미리 채움 |
| 2 | 기억에 남는 순간 | 그중에서 [○○할 때]가 제일 기억에 남는다. | 1번 행동별 순간 `extra.moments_by_act`, `extra.moments_any`, 부록 순간 `emotions[].moments` |
| 3 | 감정 | 그때 나는 [얼마나] [감정 말]. | 감정 카드 하나 (`emotions[]`, `extra.feel_default`, `extra.feel_more`) · 얼마나 "정말"은 미리 채움 |
| 4 | 마음 그리기 | 가) 내 마음은 마치 [비유 재료] 같았다. / 나) 나도 모르게 [움직임]. | 가: `emotions[].body[].materials` (가슴 칸 먼저) / 나: `emotions[].movements` 를 `extra.move_say` 로 다듬은 말 |
| 5 | 생각·다짐 | [다음에는·앞으로는] [하고 싶은 일·다짐]. | 좋은 날은 1번으로 만든 "또 ○○하고 싶다"를 미리 채움, 속상한·불편한 날은 `extra.wants`의 "~해야겠다"에서 고름 |

- 2번과 3번을 이어 읽으면 까닭이 드러나서, 까닭 문장을 따로 쓰지 않는다.
- 4번은 가, 나 중 **하나만** 고른다.
- 예시 일기는 `extra.example`.

## 2. 파일

- `index.html` 일기 쓰기 앱. 고른 내용으로 "오늘의 일기" 쪽을 인쇄/PDF 저장
- `version.js` 버전 기록. 올릴 때 여기 v·date·log 와 index.html·guide.html 의 `?v=` 숫자를 같이 바꾼다
- `guide.html` 정리본(14쪽). 같은 데이터로 그리므로 낱말을 고치면 정리본도 같이 바뀐다. 인쇄해서 `guide.pdf` 로 저장
- `data.js` = `diary5_data.json` 을 그대로 옮긴 것 / `extra.js` = 이 앱에서 새로 쓴 낱말

## 3. 데이터 구조 (`diary5_data.json`)

```
title, target
sentences[]        5문장 틀: no, step, frame, slots, sources (4번은 choose_one)
example            예시 일기 5문장
fillers[]          문장 번호별 낱말 묶음: sentence, title, groups[{label, words[]}]
places[]           장소 12곳: place, rows[{what[], how[], action{past, present, want}}]
emotion_groups[]   감정 5묶음: part, name
emotions[]         감정 30개:
                   no, part, name(기쁘다), past(기뻤다), meaning,
                   sound_words[], look_words[],
                   body[{part, materials[]}], movements[], moments[]
```

- 틀 문자열의 `[ ]` 안이 네모 칸 이름이다.
- `action.past` 는 1번, `action.want` 는 5번에 쓴다. `action.present` 는 지금은 문장에 쓰지 않는 참고용이다.

## 4. 꼭 지킬 규칙

- **조사 자동 처리**: 넣은 낱말의 마지막 글자 받침에 따라 고른다.
  - 와(과): 받침 없으면 "와", 있으면 "과" (친구와 / 동생과)
  - 을(를): 받침 없으면 "를", 있으면 "을" (그네를 / 책을)
  - 은(는): 받침 없으면 "는", 있으면 "은" (어깨는 / 발은)
  - "혼자서"처럼 조사가 필요 없는 낱말은 "와(과)"를 뺀다 (오늘 나는 혼자서 집에서 …)
- **몸 부위 낱말**: `body[].part` 는 얼굴, 가슴, 손, 발, 온몸 다섯 가지다. 몸 부위를 고르면 그 부위의 `materials` 만 보여 준다.
- **용어 통일**: 화면의 말은 아래만 쓴다.
  - 감정, 감정 말, 감정 카드, 장소 카드, 네모 메꾸기
  - 무엇, 어떻게, 행동, 얼마나, 까닭
  - 몸 부위, 비유 재료, 소리 말, 모습 말, 움직임
  - "흉내말", "마음", "아이스크림" 같은 말은 쓰지 않는다.
- **글씨와 조작**: 초1이 쓰므로 글씨는 크게, 한 화면에 한 문장씩, 낱말은 눌러서 고르는 버튼으로 한다.
- **직접 입력 허용**: 모든 네모 칸은 목록에 없는 말을 직접 쓸 수도 있어야 한다.

## 5. 자료 출처

- `emotions` 30개(뜻, 소리 말, 모습 말, 비유 재료, 움직임, 이런 순간)는 모두 새로 쓴 내용이다. 구매한 교재의 문장이나 낱말 목록을 옮긴 것이 아니다.
- 5문장 틀, 장소 카드, 까닭 낱말도 이 정리 과정에서 새로 만든 것이다.
- 감정마다 몸 부위별 비유를 고르게 하는 방식은 「마음 아이스크림 가게」(굿비잉 꼬마작가클럽)에서, 흉내 내는 말 분류는 「첫 일기쓰기 표현 가이드」(아이블 미래교육연구소)에서 아이디어를 얻었다.
