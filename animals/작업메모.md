# 작업 내용 정리

『Four Seasons for Animals』(Ashley Wolff) 영어 학습 페이지를 만들었습니다. 2026-10-12

## 만든 것

`mom-apps/animals/index.html` 와 `audio/a01.mp3 ~ a33.mp3` 입니다.
주소는 https://godpen65-jpg.github.io/mom-apps/animals/ 입니다.
13단원의 두 번째 글이고, 이야기가 아니라 사실을 알려 주는 글(informational text)입니다.

**읽기** — 책 104~114쪽을 7화면(105 / 106 / 108 / 109 / 110~111 / 112~113 / 114)으로 묶었습니다.
빈칸은 20개입니다. 이 책에 나오는 13단원 낱말 열 개
(bloom, bud, chick, curl up, hatch, hibernate, plant, puddle, scarce, store)를 모두 뚫었고,
Words to Know 중 green·new·open·fall·down 다섯 개도 넣었습니다.

13단원 낱말 스무 개는 두 책에 나뉘어 들어 있습니다.
`seasons/` 에서 열넷, 여기서 열(bud·chick·hatch·plant 네 개는 두 책에 다 나옵니다)을 다루면 스무 개가 다 채워집니다.

**문제** — 16개입니다. 단어 뜻 6개, 이야기 내용 6개, 낱말 상자 채우기 4개.

**배경** — `seasons/` 와 같은 들판 그림이고, 화면마다 계절 색이 바뀝니다.

## 소리

문장 33개, Archie(남성) 목소리입니다.

공통으로 지키는 것 (랭콘 네 앱이 같습니다)
- 영어 제목 크게, 한글 제목은 `한글 제목 보이기` 를 눌러야 나옵니다. (`langcon-show-kr`)
- 읽기 화면에 `⏭ 다음 쪽` 단추가 있어 다 채우지 않아도 넘어갑니다.
- 책 상자는 화면 높이에 고정되고, 글이 길면 글자가 저절로 줄어듭니다(`fitText`).
- 빈칸을 맞히면 단원 낱말은 초록 굵은 밑줄, 책 형광펜 단어는 노란 바탕입니다.
- 문제 화면의 `다음 ▶` 은 상자 안 오른쪽 위에 있습니다.
- 뒤로 가기(←)는 `../langcon/` 으로 갑니다.

## 내용 고치는 법

`const VOCA` / `const SAME` / `const PAGES` / `var QUIZ` / `var BANK` 다섯 덩어리만 고치면 됩니다.
`PAGES` 의 `season` 값(spring·summer·fall·winter)이 그 화면의 배경색을 정합니다.

## 2026-10-12 글씨 크기 통일

쪽마다 글씨 크기가 달라 보기 불편하다고 하셔서, 칸에 맞게 저절로 줄이던 기능(`fitText`)을 뺐습니다.
이제 글씨 크기는 `.txt` 의 `--fs` 하나로만 정해집니다.
화면이 넓으면 20px, 좁거나 낮으면 19px 또는 18px 이고, 한 기기 안에서는 쪽을 넘겨도 늘 같습니다.
글이 길어 칸을 넘치면 글자를 줄이는 대신 글 칸 안에서 조금 스크롤됩니다.

소리(🔊) 단추는 글씨 첫 줄 한가운데에 맞췄습니다.
`margin-top:calc((var(--fs) * 1.55 - 34px) / 2)` 로, 글자 크기가 바뀌어도 늘 첫 줄과 나란합니다.
단추 크기는 34px 그대로 뒀습니다. 아이가 누르기에 더 작으면 불편해서요.

확인한 결과 (네 앱 모두)
- 1280x800 / 1138x712 / 1024x600 / 820x1180 — 한 기기 안에서 글씨 크기 한 가지, 넘치는 쪽 없음
  (seasons 1024x600 에서만 한 쪽이 조금 넘칩니다)
- 390x844 휴대폰 — 글씨 19px 한 가지, 글 많은 쪽 1~3개가 글 칸 안에서 스크롤됩니다

## 홈 화면 앱 아이콘 (2026-10-13)

- 홈 화면 이름 **랭콘동물**, 아이콘은 목록 이모지 그대로, 배경색 `#f6ead9`
- 넣은 파일: `manifest.json`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`
- `index.html` `<head>`의 `<!-- 홈 화면 앱 설치용 -->` 아래 4줄이 이 파일들을 연결함
- 크롬에서 열고 ⋮ → 홈 화면에 추가 하면 주소창 없이 앱처럼 열림
- 전체 정리: mom-apps 저장소의 `홈화면_앱아이콘_메모.md`
- 크롬 자동 설치 팝업은 막고, 오른쪽 아래에 앱 아이콘 + '홈 화면에 추가' 작은 버튼을 띄움 (`install.js`). 설치했거나 앱으로 열면 안 보임
