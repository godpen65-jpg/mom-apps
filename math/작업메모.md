# 작업 내용 정리

초1 수학 일일 학습지 — A5 한 장에 하루치. 2026-10-20

- `수학학습지_1일차.pdf` ~ `3일차.pdf`: 하루 한 장 (A5, 148×210mm)
- `수학학습지_정답.pdf`: 엄마 아빠용 정답 (3일치를 한 장에)
- 캐릭터는 직접 그린 분홍 토끼 「코코」 (`학습지.html` 안의 SVG)

## 문제 고치는 법
`학습지.html` 의 `DAYS` 에서 고칩니다. 날짜를 하나 더 넣으면 4일차도 같은 모양으로 나옵니다.
정답은 식에서 저절로 계산돼서 정답지에도 바로 들어갑니다.
브라우저에서 `학습지.html?day=1` 로 열고 인쇄 → 용지 A5, 배경 그래픽 켜기로 PDF 저장해도 됩니다.

## 원래 문제에서 바꾼 것
- 3일 차 1번: 「점심에 3개를 더 마셨습니다」인데 식이 `8 - 2 + 3` 이어서 `8 - 2 - 3` 으로 고쳤습니다 (답 3개).
