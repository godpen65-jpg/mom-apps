# 품사 놀이터 작업메모

주소: https://godpen65-jpg.github.io/mom-apps/parts-of-speech/

초1이 명사·동사·형용사·부사를 한국어와 영어로 같이 익히는 앱. 홈 화면 아이콘은 🧺, 배경색 `#ece8fb`.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 본체: 배우기 → 같이 하자!(동사 비법) → 바구니에 넣기 → 문장 탐정 |
| `print.html` | 종이 문제지. 열 때마다 새 문제, `?no=번호`로 같은 문제 다시 뽑기, 정답지 끄고 켜기 |
| `pos-data.js` | 낱말·문장 데이터. 앱과 문제지가 같이 씀. 낱말이나 문장을 늘리려면 여기만 고치면 됨 |
| `manifest.json`, `icon-*.png`, `apple-touch-icon.png`, `install.js` | 홈 화면 앱 설치용 (다른 앱과 같은 방식) |

## 동사를 어려워해서 넣은 것

- "같이 ○○자! / Let's ○○!"가 말이 되면 동사. 같이 크자? Let's big? 은 이상함 → 형용사
- 배우기 카드에 달리다 → 달려요, run → runs 처럼 문장 속 모양을 같이 보여줌
- 문장 탐정에서 틀리면 위치 힌트(한국어 동사는 맨 끝, 영어 동사는 명사(이름씨) 바로 뒤), 두 번 틀리면 정답이 반짝임
- 결과 화면에 가족별 점수, 약한 가족 연습 버튼
