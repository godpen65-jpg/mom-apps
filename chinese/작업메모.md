# 작업 내용 정리

중국어 인증제 연습 앱 — 목업(첫 판)입니다. 2026-09-22

주소: https://godpen65-jpg.github.io/mom-apps/chinese/ (main 에 합쳐진 뒤)

## 시험
- 2026년 동광 중국어 인증제, 12월 14일(월)~18일(금) 중 첫 중국어 시간
- 1학년 범위: 『发音, 你好! 1』(발음1) 전체 + 『汉语, 你是谁? 1』(스토리1) 전체
- 객관식 40문항. 특급 90점, 1급 70점, 2급 50점

## 공부 방식 (2026-09-22 바꿈)
하루 10분, **20일에 한 바퀴, 3바퀴** (60일). 9월 23일부터 매일 하면 11월 21일에 끝나고,
시험까지 3주는 빠진 날 채우기와 마지막 모의고사용 여유입니다.
날짜가 아니라 「다음 날」 순서로 넘어가서, 하루 빠져도 밀리지 않습니다. 첫 화면에 계획 대비 앞/뒤를 보여 줍니다.

이야기가 더 어려워서 **이야기를 매일** 봅니다 (발음 먼저 몰아서 하지 않음).
- 하루: 이야기 카드 5~6개 + 발음 카드 4~5개 → 문제 10개 → 도장
- 1~6일 이야기①, 7~12일 이야기②, 13~18일 이야기③. 6·12·18일은 이야기 전체 이어 듣기
- 발음: 1일 성조, 2일 모음, 3~16일 발음책 단어(첫소리 순서), 17~18일 인사말
- 19일 ★ 총복습(문제 15개), 20일 모의고사 40문제(발음 16 + 회화 24)
- 문제는 오늘 것 7할 + 지난 날 복습, 틀렸던 것이 먼저 나옴. ★ 는 두 배로 자주 나옴
- 바퀴마다: 1바퀴 익히기(뜻 보임, 이야기 6:발음 4) → 2바퀴 떠올리기(뜻 가림, 눌러서 확인, 7:3)
  → 3바퀴 실전(카드 없이 바로 15문제, 틀린 것만 카드로)
- 3바퀴 끝나면 큰 단추가 「모의고사 40문제」로 바뀜
- 도장판(60칸)에서 지난 날을 눌러 다시 할 수 있음 (진도는 안 바뀜)

하루 계획은 `index.html` 의 `STORY_PLAN`(이야기 날마다 단어·문장), `PRON_PLAN`(발음) 에서 고칩니다.

## 화면 (2026-09-23 바꿈) — 갤럭시 탭 가로용
갤럭시 탭을 눕혀서 쓰므로 **한 화면에 다 들어가고 스크롤이 없게** 했습니다.
- 첫 화면: 왼쪽 오늘 공부 큰 단추, 오른쪽 도장판(바퀴마다 10칸 두 줄)과 메뉴 3개
- 공부 카드: **한 장씩 크게**. ◀ ▶ 또는 손가락으로 밀어서 넘김. 카드가 나오면 바로 읽어 줌.
  성조·첫소리·문장 틀은 카드 한 장 안의 판으로 보여 줌. 마지막 카드에서 「문제 풀기」 단추가 나옴
- 이어 듣기 날에는 「처음부터 끝까지 듣기」를 누르면 읽으면서 카드가 저절로 넘어감
- 문제: 왼쪽 질문, 오른쪽 보기. 정답 풀이와 「다음」 단추도 오른쪽 아래
- 결과: 왼쪽 점수·도장, 오른쪽 틀린 것 목록
- 꼭 외울 것: 탭 5개(성조, 첫소리 21, 자꾸 나오는 문장, 문장 틀, 헷갈리는 짝)
- 1280×720, 1024×600 가로 화면에서 60일 전부 넘겨 보며 스크롤·잘림 없음을 확인
- 폰이나 세로로 들면 위아래로 쌓이고 스크롤됩니다

## 그 밖의 메뉴
- **꼭 외울 것**: 성조, 첫소리 21개와 대표 단어, 자꾸 나오는 문장, 문장 틀 5개, 규칙 2개, 헷갈리는 짝
- **교재 전체 보기**: 단원별 카드
- **틀린 문제 다시**: 맞히면 목록에서 빠짐
- 모든 문제는 객관식이고, 매번 새로 섞어서 만듭니다
- **한글 발음** 단추: 기본은 꺼짐. 켜면 카드와 정답 풀이에 한글 발음이 나옵니다 (`chinese-show-kr`)

## 소리
지금은 폰에 들어 있는 중국어 목소리로 **한자**를 읽게 합니다 (성조가 맞게 나오도록).
CD 음원을 넣을 때는 `chinese/audio/` 에 mp3를 두고, 해당 낱말·문장 데이터에 `a:'파일이름.mp3'` 를 붙이면
그 파일을 먼저 재생합니다. 파일이 없거나 재생이 안 되면 폰 목소리로 넘어갑니다.

## 데이터 고치는 곳
`index.html` 위쪽 `PWORDS`(발음책 단어), `PSENT`, `S1W/S1S`, `S2W/S2S`, `S3W/S3S`(이야기 단어·문장).
배열 칸 순서: 병음, 한자, 뜻, 한글 발음, ★(1이면 꼭 외울 것).

저장 열쇠: `chinese-cert-v1` (pos 진도, stamps 도장, wrong 틀린 문제, best 모의고사 최고 점수)
