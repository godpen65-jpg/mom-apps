# 교육청 무료 자료 모음 (edu-links)

초1 대상 문해력·글쓰기 자료 8개 링크 페이지. `index.html` 한 장짜리.

## 고른 기준

1. 시·도교육청이 만들어 **무료로 공개**한 자료
2. **회원가입·로그인 없이** 받아지는 것 (교사 계정 필요한 건 제외)
3. **초1 수준**에 맞는 것 (초3~6용, 중·고용은 제외)
4. 보도자료만 있고 원문 파일이 없는 건 제외

## 실은 자료

| # | 교육청 | 자료 |
|---|---|---|
| 1 | 대전 | 하루읽기로 읽기가 술술 (기초단계) =「초등학생 첫 읽기책」 |

| 3 | 전북 | 손바닥 그림책 4세트 + 「우리 아이 읽기 쓰기 어떻게 지도할까?」 |

## 빠진 자료와 이유

- **KRI 읽기 검사지** (교육부·17개 교육청·평가원) — 매일 푸는 교재가 아니라 기초학력 진단 도구
- **강원 「글이 술술 셈이 술술」** — 교사 계정 필요
- **충남 첫걸음 한글 / 키득키득** — 찬찬한글과 겹침
- **부산 또랑또랑 읽기·또박또박 쓰기, 대구 문해력 똑똑 읽기 첫 걸음, 세종 초기 문해력 카드뉴스**
  — 학교 배부용이라 원문 PDF가 공개 게시판에 없음
- **제주 읽기쓰기 100단계, 서울 북돋움** — 검토 후 제외

## 주의할 점

- **경기 온국어**는 학습지 파일 제작일이 2021년 7·11월로 **2015 개정 교육과정 기준**.
  지금 초1은 2022 개정 교과서라 단원 번호·순서가 맞지 않음.
  페이지에도 "단원 번호는 신경 쓰지 말고 필요한 주제만 골라 쓰라"고 적어둠.
- **전북 손바닥 그림책**은 도서로 출판·판매 중. 가정·교육 목적 활용은 가능하나
  대량 복제·배포·영리 이용 금지. 페이지에 표기함.
- **충남**은 게시판 링크라 개별 게시물 딥링크가 아님. 게시판에서 직접 찾아야 함.
  (게시물 링크가 JS 앵커라 고정 URL을 못 뽑음)
- 교육청 홈페이지는 주소가 자주 바뀜. 링크 깨지면 확인 필요.

## 확인 못 한 것

- 인천 「생각이 깊어지는 글쓰기」 — zip 내부까지는 확인 안 함.
  공개 게시물 제목은 "학생용 교재, 교사용지도서(각 9종)"이고 1~2학년군 교재가
  별도로 있다는 건 인천 교사 포털 검색 결과로 확인.

## 디자인

- 본체(`/index.html`)는 분홍 계열, 이 페이지는 **민트·연두 계열**로 구분.
- 폰트는 본체와 동일 (Jua + Gaegu).
- 카드 구조도 본체와 같은 `.card > .card-row > .badge + .card-text + .arrow`.
- 맨 위에 "이 순서로 쓰면 돼요" 6단계 안내 박스 (연두 톤).
